# 🚀 MERN Authentication System (Login & Registration)

> A full-stack authentication system built using the MERN stack with user registration and login functionality.

---

## 📖 Project Description

This is my **first full-stack MERN project**, where I built a basic authentication system to understand how frontend and backend work together.

The project connects a **React frontend** with a **Node.js & Express backend**, and stores user data in **MongoDB**.

---

## ✨ Features

- ✅ User Registration  
- ✅ User Login  
- ✅ MongoDB Database Integration  
- ✅ REST API with Express  
- ✅ React Frontend (Form Handling + Axios)  

---

## 🛠 Tech Stack

| Frontend | Backend | Database |
|----------|--------|----------|
| React.js | Node.js | MongoDB |
| Axios    | Express | Mongoose |

## ⚙️ Installation & Setup

### 🔹 Clone the repository

```bash
git clone https://github.com/manas1137/mern-login-reg.git
cd mern-login-reg

🔹 Backend Setup
cd backend
npm install
npm start

🔹 Frontend Setup
cd frontend
npm install
npm run dev
